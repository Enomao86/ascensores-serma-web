# Ascensores SERMA — 
Proyecto Next.js preparado para Vercel.

## Ejecutar

```bash
npm install
npm run dev
```

Abrir http://localhost:3000

## Compilar

```bash
npm run build
```

## Identidad

- `public/logo-serma-oficial.png`: logo horizontal oficial, sin alterar su diseño.
- `public/logo-serma-piramide.png`: recorte del mismo archivo oficial usado en la intro.
